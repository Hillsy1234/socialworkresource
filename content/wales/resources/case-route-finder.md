# Wales case route finder

## Build a learning route

Select the features present in a fictional situation. Suggestions show topics that may need attention together. They do not decide eligibility, capacity, safeguarding thresholds or authority to detain.

## Use the results

1. Read each suggested module and its official sources.
2. Identify the person’s account, missing evidence and any immediate safety action.
3. Explain which duties or processes may apply and why.
4. Record uncertainties for supervision or legal advice.
5. Set the next action, responsible person and review date.

A route is a learning aid, not a substitute for a full assessment. An unselected feature may still be relevant.
