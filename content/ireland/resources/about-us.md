# About Us — Ireland

## About this resource

Daily Mindset Moments CIC, founded by Raymond Hill, provides this structured social-work learning resource. It supports students, practitioners and supervisors with modules, fictional exercises, source links and private reflections.

## Ireland context

This guide separates the learning material for Ireland from the other practice locations. Shared theories support enquiry; laws, professional requirements and service pathways must be checked locally. Read the source library for scope and editorial status.
