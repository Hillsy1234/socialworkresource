Search coverage and queries
A successful source check is not a professional review. Source checks cover the registered pages and feeds; web-search discovery adds selected queries when enabled. Searches use one provider, primarily English-language results, and bounded result pages, so material can still be missed. They do not certify that guidance is current, determine when a law takes effect or check every linked document. Changes and failed checks need editorial attention. Learning content is never edited by this monitor.
